# Guía de Ejecución Local

Instrucciones para levantar y gestionar el servidor de desarrollo local del proyecto.

---

## 🚀 Levantar el Servidor Local

Para iniciar el servidor local de desarrollo manualmente en tu terminal, ejecuta:

```bash
npm run dev
```

---

## 📋 Pasos Detallados

1. **Abrir la terminal en la raíz del proyecto:**
   Asegúrate de encontrarte en la carpeta del repositorio:
   ```powershell
   cd c:\Users\vicho\Desktop\Portfolio_V_D
   ```

2. **Ejecutar el comando de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Abrir en el navegador:**
   Por defecto, Vite iniciará el servidor en:
   👉 **http://localhost:5173/**

4. **Detener el servidor:**
   Presiona `Ctrl + C` en la consola para pausar o finalizar el proceso.

---

## 🛠️ Otros Comandos Útiles

| Comando | Descripción |
| :--- | :--- |
| `npm run dev` | Inicia el servidor de desarrollo local con recarga rápida (HMR). |
| `npm run build` | Compila y optimiza el proyecto para producción en la carpeta `dist`. |
| `npm run preview` | Levanta un servidor local para previsualizar la compilación de producción generada por `build`. |
